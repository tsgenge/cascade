# CascadeEsdm.Messaging.AzureServiceBus

Azure Service Bus message receiver for the [Cascade ESDM](https://github.com/tsgenge/cascade) policy listener.

## Installation

```bash
dotnet add package CascadeEsdm.Messaging.AzureServiceBus
```
