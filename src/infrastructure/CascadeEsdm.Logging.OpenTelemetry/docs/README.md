# CascadeEsdm.Logging.OpenTelemetry

OpenTelemetry-based structured logging and Application Insights integration for the [Cascade ESDM](https://github.com/tsgenge/cascade) framework.

## Installation

```bash
dotnet add package CascadeEsdm.Logging.OpenTelemetry
```

## Documentation

For full documentation, conventions, and examples: [github.com/tsgenge/cascade](https://github.com/tsgenge/cascade)
