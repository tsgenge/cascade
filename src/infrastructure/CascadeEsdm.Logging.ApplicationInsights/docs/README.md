# CascadeEsdm.Logging.ApplicationInsights

Application Insights based structured logging integration for the [Cascade ESDM](https://github.com/tsgenge/cascade) framework.

## Installation

```bash
dotnet add package CascadeEsdm.Logging.ApplicationInsights
```
