# CascadeEsdm.Storage.Azure

Azure Table Storage implementation of `ITableStore<TEntity>` for the [Cascade ESDM](https://github.com/tsgenge/cascade) framework.

## Installation

```bash
dotnet add package CascadeEsdm.Storage.Azure
```
