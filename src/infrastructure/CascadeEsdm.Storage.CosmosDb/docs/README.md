# CascadeEsdm.Storage.CosmosDb

Azure Cosmos DB event stream and read model storage provider for the [Cascade ESDM](https://github.com/tsgenge/cascade) framework.

## Installation

```bash
dotnet add package CascadeEsdm.Storage.CosmosDb
```

## Documentation

For full documentation, conventions, and examples: [github.com/tsgenge/cascade](https://github.com/tsgenge/cascade)
