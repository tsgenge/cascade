# CascadeEsdm.DistributedLocks

Azure Blob Storage distributed lock provider for aggregate-level concurrency in the [Cascade ESDM](https://github.com/tsgenge/cascade) framework.

## Installation

```bash
dotnet add package CascadeEsdm.DistributedLocks
```

## Documentation

For full documentation, conventions, and examples: [github.com/tsgenge/cascade](https://github.com/tsgenge/cascade)
