# CascadeEsdm.SharedKernel.Abstractions

Core abstractions for the [Cascade ESDM](https://github.com/tsgenge/cascade) framework — `IDomainEvent`, `IAggregateRoot`, `IEventApplier`, `IValueObject<T>`, `Subject`, and `EventEnvelope`. No external dependencies; reference this in your domain layer without coupling to infrastructure.

## Installation

```bash
dotnet add package CascadeEsdm.SharedKernel.Abstractions
```

## Documentation

For full documentation, conventions, and examples: [github.com/tsgenge/cascade](https://github.com/tsgenge/cascade)
