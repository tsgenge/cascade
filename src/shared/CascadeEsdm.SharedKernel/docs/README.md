# CascadeEsdm.SharedKernel

Base implementations for aggregates, value objects, and shared kernel types in the [Cascade ESDM](https://github.com/tsgenge/cascade) framework. Includes `CascadeEsdm.SharedKernel.Abstractions` as a dependency.

## Installation

```bash
dotnet add package CascadeEsdm.SharedKernel
```

## Documentation

For full documentation, conventions, and examples: [github.com/tsgenge/cascade](https://github.com/tsgenge/cascade)
