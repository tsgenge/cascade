# CascadeEsdm.ReadModel.Abstractions

Read-side interfaces for the [Cascade ESDM](https://github.com/tsgenge/cascade) framework — view definitions (`IView`), projection entry points (`IViewProjector<TView>`), query handlers, and partition resolution. Its only dependency is `CascadeEsdm.SharedKernel.Abstractions`.

## Installation

```bash
dotnet add package CascadeEsdm.ReadModel.Abstractions
```

## Documentation

For full documentation, conventions, and examples: [github.com/tsgenge/cascade](https://github.com/tsgenge/cascade)
