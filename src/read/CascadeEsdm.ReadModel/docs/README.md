# CascadeEsdm.ReadModel

Read model infrastructure for the [Cascade ESDM](https://github.com/tsgenge/cascade) framework — concrete projectors, query handlers, and view materialisation. Includes `CascadeEsdm.ReadModel.Abstractions` as a dependency.

## Installation

```bash
dotnet add package CascadeEsdm.ReadModel
```

## Documentation

For full documentation, conventions, and examples: [github.com/tsgenge/cascade](https://github.com/tsgenge/cascade)
