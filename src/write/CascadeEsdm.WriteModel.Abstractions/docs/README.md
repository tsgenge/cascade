# CascadeEsdm.WriteModel.Abstractions

Write-side interfaces for the [Cascade ESDM](https://github.com/tsgenge/cascade) framework — `ICommand`, `ICommandExecutor`, `ICommandEnvelope`, and command handling contracts.

## Installation

```bash
dotnet add package CascadeEsdm.WriteModel.Abstractions
```

## Documentation

For full documentation, conventions, and examples: [github.com/tsgenge/cascade](https://github.com/tsgenge/cascade)
