# CascadeEsdm.WriteModel

Command dispatch, aggregate hydration, event stream writing, concurrency handling, and MSBuild integration for the [Cascade ESDM](https://github.com/tsgenge/cascade) framework. Includes `CascadeEsdm.WriteModel.Abstractions` and `CascadeEsdm.SharedKernel` as dependencies.

## Installation

```bash
dotnet add package CascadeEsdm.WriteModel
```

## Documentation

For full documentation, conventions, and examples: [github.com/tsgenge/cascade](https://github.com/tsgenge/cascade)
